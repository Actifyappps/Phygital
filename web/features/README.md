# Web feature surfaces

Feature folders correspond to user tasks and surfaces, not independent sources of business truth. Every mutation maps to an authorised command and domain owner. Public projections must be explicitly approved and exclude private evidence, personal data and confidential buyer terms.

See [surface and navigation map](../../docs/product/surface-and-navigation-map.md).

## Feature ownership
- `public-marketplace/`: anonymous discovery and public-safe listing projection.
- `buyer/`: buyer requirements, enquiry, quotation and order experience.
- `supplier/`: producer/supplier assisted journeys.
- `hub-services/`: facility-scoped service workflows.
- `seller-exporter/`: separately authorised legal capacities; no combined permission.
- `operations/`: restricted platform operations and support.
- `oversight/`: reviewer/assurance workflows.
- `notifications/`: user notices and delivery outcomes.
- `product-passport/`: revocable read-only passport/QR projection.
- `partner-readiness/`: scoped facility/provider assessments.
- `marketplace-trust/`, `product-integrity/`, `compliance/`, `commercial-services/`: dedicated trust, recall, rule and service/fee features.
