# Architecture readiness checklist

Do not begin production implementation until the following are resolved by authorised decision-makers and supported by evidence.

- [ ] Current source hierarchy and versions confirmed.
- [ ] 024-R findings dispositioned by responsible owners; source specifications amended where required.
- [ ] 024-A permission tuples and seller/exporter mandate lifecycle reviewed.
- [ ] 024-B workflows and state ownership reconciled with physical service model.
- [ ] 024-C logical model reconciled with 018-A decisions and migration findings.
- [ ] 024-D contracts versioned and provider boundaries approved.
- [ ] 024-E accessibility, language, offline and surface requirements reviewed.
- [ ] 024-F privacy/security threat model and retention controls reviewed by competent specialists.
- [ ] 024-G acceptance cases and evidence semantics agreed.
- [ ] TSBBF decision completed for framework, hosting, database, identity, storage, integrations and build-vs-buy.
- [ ] AADDG repository, CI/CD, secret, migration, environment, backup and recovery controls applied.
- [ ] Physical facility/service scope and named operators validated.
- [ ] Buyer, producer, exporter, payment and logistics/provider evidence obtained.
- [ ] Migration 001 HOLD formally resolved or replaced through an approved migration decision.
- [ ] Offline rehearsal and EVI-21 independently closed.
- [ ] Release gates, rollback, observability and incident ownership demonstrated.
- [ ] No live-trade capability enabled until separate sponsor/legal/partner approvals.
