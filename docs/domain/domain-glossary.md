# Domain glossary — controlled working vocabulary

| Term | Meaning / boundary |
|---|---|
| Source organisation | Producer/cooperative group from which supply originates |
| Seller | Legal party contracting to sell goods to buyer |
| Exporter of record | Separately authorised party responsible for export role |
| Hub service operator | Provides agreed facility services; not automatically custodian |
| Batch | Identified physical product lot with source and evidence lineage |
| Declared supply | Participant assertion; not verified stock |
| Received quantity | Quantity recorded at an authorised intake event |
| Eligible quantity | Quantity meeting defined evidence/specification gates |
| Reservation/allocation | Digital reservation against eligible quantity; not physical movement |
| Movement | Separately evidenced physical change of location/possession |
| Dispatch | Physical handover to an authorised carrier under an approved operating model |
| Evidence class | E1–E4 strength of support for a specific claim |
| Provenance type | How evidence was obtained or recorded |
| Accepted quotation | Commercial offer accepted under the defined workflow |
| Commercial snapshot | Immutable accepted terms retained with the order |
| Payment status | Reported/verified status from evidence/provider; not platform receipt of funds |
| Shipment milestone | Evidence-backed event in an authorised logistics process |

Use the 024 series and governing source documents for full definitions. Where ordinary language conflicts with these controlled meanings, controlled meanings prevail in system labels and tests.
