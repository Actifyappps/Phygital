# Security workspace

024-F and 024-A are the security and authority requirements baseline. This folder is not a security certification or penetration-test report. Findings require evidence, severity, owner role, remediation, retest and reviewer disposition.

024-F crosswalk: `024f-control-and-test-crosswalk.md` maps security/privacy/threat/abuse requirements, SEC-001–020 and ST-01–24. Existing topic documents remain authoritative for their detailed domains; this crosswalk is the source-to-repository index.

- `024f-control-requirement-catalogue.md` — complete source-level threat, control and test catalogue for TH-01–TH-20, SEC-001–SEC-020 and ST-01–ST-24.
